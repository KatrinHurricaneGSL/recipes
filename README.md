# Что приготовить?

Веб-приложение для поиска рецептов и просмотра инструкций приготовления. Данные загружаются из публичного API DummyJSON.

## Возможности

- Вывод каталога рецептов.
- Поиск по названию рецепта.
- Пагинация.
- Страница с подробным описание рецепта.
- Адаптивная вёрстка.

## Технологии

- **TypeScript**
- **Vite**
- **HTML**
- **CSS**
- **Fetch API**
- **lodash.debounce**
- **Lucide**

## Запуск

Минимальная версия Node.js `20.19+`.

В каталоге проекта выполните:

```sh
npm install
npm run dev
```

Откройте адрес, который выведет Vite в терминале.

## Команды

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Запустить сервер разработки |
| `npm run build` | Проверить TypeScript и собрать проект в `dist/` |
| `npm run preview` | Локально просмотреть собранную версию |

Для просмотра сборки:

```sh
npm run build
npm run preview
```

## Страницы

| Адрес | Содержимое |
| --- | --- |
| `/` | Каталог рецептов |
| `/?search=Chicken&page=2` | Пример поиска с указанием страницы |
| `/recipe.html?id=1` | Рецепт с указанным идентификатором |

## Источник данных

Базовый адрес API задан в `src/api.ts`: `https://dummyjson.com`.

Приложение использует следующие запросы:

- `GET /recipes?limit=6&skip=0` — список рецептов.
- `GET /recipes/search?q=Chicken&limit=6&skip=0` — поиск.
- `GET /recipes/1` — отдельный рецепт.

Размер страницы задаётся константой `PAGE_SIZE` в `src/pagination.ts`.
